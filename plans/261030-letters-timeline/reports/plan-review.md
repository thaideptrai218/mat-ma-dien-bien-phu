## Required implementation details

1. **Separate story order from crossword order.** Existing `crosswordRows = clues.map(...)` couples row IDs and positional offsets. Reordering `clues` directly would corrupt `TIMTVAL`. Define explicit crossword row IDs `objective, encirclement, a1, headquarters, weapons, north, independence` with offsets `8,7,8,0,8,3,5`, and resolve answer/question by ID. Define a separate chronological ID list starting `encirclement, objective`. Notebook, next goal and chronology rules consume the latter; puzzle grid/questions consume explicit rows. Do not change answers or cipher boards.

2. **Unlock the next item only after collection.** One shared helper should return the first chronological ID absent from `collectedClueIds`. Reducer `discover-clue` accepts only this ID (or idempotent already-found records); future discovery leaves state unchanged. Add `readLetterIds: []` to `createTrialState`. `complete-letter` requires valid/discovered/current ID, is idempotent, and never collects. `collect-clue` requires discovered + read letter + current ID. Reading a letter alone must leave later letters locked until Minh's reflection is completed and collected. Avoid separate ad-hoc order logic in controller/UI.

3. **Preserve the controller's reflection gate.** Existing collection verifies `getActiveNarrative().lastLine` and matching clue ID. Preserve it. New letter-to-reflection intent must verify matching active letter, final page and discovered/current-or-previously-collected item before committing `complete-letter`; `ui.showClue` alone must never mark a letter read. Open notebook replay through `read-clue`, retaining its discovered check. After a failed collect commit, do not close or announce success; current `collectClue` unconditionally reports success, which becomes misleading with stronger reducer guards.

4. **Read and reread stay distinct from collection.** Reopening a found letter resumes its page, including when interrupted on the last page; it must still require the explicit reflection action. Already-collected items may replay letter/reflection regardless of the current timeline position. Store page cursors separately from reflection cursors; reset both in `resetDrafts`. Existing `TrialSession.start()` replaces reducer state and calls `resetDrafts`, so no save migration or session changes are required. Verify reset clears read IDs, discovered/collected IDs, both cursor kinds and puzzle drafts.

5. **Keep one native dialog and explicit focus on redraw.** Existing `TrialInterface.open` clears narrative state, replaces dialog content, preserves the original outside opener and focuses a heading asynchronously. Reuse that dialog for the paper view; do not nest a second modal. Set a distinct `letter` kind and clear active-letter state when changing panels/closing/resetting. Page redraw replaces buttons: explicitly move focus to an appropriate page heading/control and reset scroll to the page start so keyboard users are not left on detached nodes. Letter-to-reflection must keep input blocked throughout. Test Escape/backdrop, Tab/Shift+Tab, close/reopen from notebook, transition to reflection, and return to canvas. Existing session handles sound/input suppression through `onModalChange`.

6. **The bridge must depend on the same three IDs, irrespective of order.** Existing `BRIDGE_REQUIREMENTS` checks `objective, encirclement, a1` by membership; retain it. Swap the two east-side clue IDs/labels/coordinates together and preserve their interaction radii. East-side collection must be `encirclement → objective → a1`; only then open the bridge, making `headquarters` the current item. All later clues already lie on the accessible west side. Run the existing reachability tests after the swap and play the complete route; update bridge/map prose to chronological order. Never make an east-side requirement depend on a west-side clue.

7. **Font repair needs all rendering surfaces.** Current DOM prose uses Georgia/Cambria, HUD Segoe UI/Tahoma, SVG map uses inline family attributes, and `archive-art.js` bakes Canvas text once during `TrialScene.create`. No bundled fonts currently exist. Adding a CSS font alone cannot fix those inline/baked surfaces. If using a local font, include its license and Vietnamese glyphs, load required weights before creating Canvas text, apply it to prose/HUD/SVG/Canvas, then visually verify real affected words. Preserve native text shaping; normalize authored Vietnamese to NFC. Plain paper text should not be split into character spans. ASCII cipher splitting is unrelated and can remain. Do not claim NFC alone proves the visual defect fixed.

8. **Update changed test contracts intentionally.** Existing rule tests assert original `clues` order and `collectAll()` currently does discover → collect. Move fixed row-order assertions to `crosswordRows`; assert chronological IDs separately and add `complete-letter` to fixtures. Preserve original exact puzzle output tests and geometry checks. Add meaningful cases for future discover/read/collect rejection, collection before letter completion, invalid/repeated IDs, no unlock before reflection collection, prior-clue replay, immutable transitions, and complete end-to-end puzzle progression. Controller/browser checks must also reject letter completion before final page and collection outside the final reflection; reducer tests alone cannot establish those UI conditions.

- Source the campaign, A1/HQ timing, campaign totals and final troop-withdrawal milestone before finalizing dates. The proposed `north: 17/5/1955` and next-day retrospective avoid conflating July 1954 agreement signing with completed northern withdrawal; a sources report must support the chosen milestone and describe invented narrator experiences. Weapons letter must be dated after the HQ event and avoid presenting the total as all prisoners.
- Existing intro/welcome/header currently say `1–7/5/1954`; include them in timeline copy review once the scope reaches April 1954–May 1955. Changing only letters leaves the shell inconsistent.
- Browser evidence: paper, final-page button, reflection, notebook timeline and replay; long paragraphs at 375px and desktop, 200% zoom; actual diacritics across DOM/SVG/Canvas; offline local font; no horizontal page overflow; M/N/Q/Shift behavior; bridge and both puzzles/chest completion. Build both entry points and run existing main-game tests to check isolation.
